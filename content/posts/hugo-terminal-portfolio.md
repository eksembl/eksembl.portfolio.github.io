Портфолио теперь — статический сайт на [Hugo](https://gohugo.io/) с темой Terminal. Вместо клиентского React-приложения каждая страница отдаётся готовым HTML: быстрее загрузка, проще SEO и меньше точек отказа.

### Почему Hugo

- **Скорость.** Сборка всего сайта занимает меньше секунды.
- **Ноль JavaScript для контента.** Страницы читаются даже с отключёнными скриптами.
- **Markdown.** Проекты и заметки — обычные `.md`-файлы в репозитории.

### Как устроен деплой

Пуш в `main` запускает GitHub Actions: workflow ставит Hugo Extended, собирает сайт и публикует артефакт через GitHub Pages.

```yaml
- name: Build
  run: hugo --gc --minify
```

Сайт собран и опубликован на `eksembl.dev`. Деплой полностью автоматический: пуш в `main` — и через минуту изменения уже в сети.

### Что получилось

- быстрые статические страницы с собственными метатегами и OG-изображениями;
- проекты и заметки в Markdown — без базы данных и админки;
- единый терминальный стиль, включая 404 и RSS;
- поисковая разметка JSON-LD и sitemap.
